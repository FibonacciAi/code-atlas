# Public demonstration media

The GitHub Pages gallery shows the actual Code Atlas interface from the public 0.3.3 source. All file names, source text, documents, and geometric artwork in the captures are generated examples.

The capture application uses an isolated entry point with an explicit generated folder. It does not restore normal app preferences or saved folders, discover real repositories, contact Personal, or read private graph state. Its window is labeled **Synthetic Sample** throughout.

Only that application's window is captured. Desktop chrome, other applications, notifications, and microphone audio are excluded. Screenshots are PNG; the demonstration video is a silent H.264 MP4. Capture metadata is stripped before publication.

The recording uses timed calls to the existing Map, City, focus, reader, preview, and return actions. It demonstrates those views and transitions; it is not a performance benchmark or a recording of physical trackpad input.

Published media:

- Map overview
- City overview
- Source reader
- Markdown document reader
- Image preview
- A short, silent sequence through the same views

The website has no analytics, forms, file upload, connection to the native app, or third-party scripts. GitHub supplies the hosting infrastructure. Repository links lead to the public app source.
